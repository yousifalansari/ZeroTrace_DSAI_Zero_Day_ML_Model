## Dataset

UNSW-NB15 official training and testing partitions (Moustafa and Slay, 2015).

* Official source: https://research.unsw.edu.au/projects/unsw-nb15-dataset (folder "Training and Testing Sets")
* Mirror used by the team: https://www.kaggle.com/datasets/dhoogla/unswnb15

Save the two files as:

| File | Rows | Columns | SHA-256 |
|---|---|---|---|
| `data/train.csv` | 175,341 | 45 | `bec7dd5ec88dc2a0ccc7a07879d338395ed7421750f675fd0339e07dfe0648fa` |
| `data/test.csv` | 82,332 | 45 | `734fe6642edf758f7c94d7d9149426b49d202fe8e7bf0bef47392489c3c0a559` |

Note: in some copies of the original release, the file named `UNSW_NB15_testing-set.csv` holds 175,341 rows and
`UNSW_NB15_training-set.csv` holds 82,332. Rename by row count: the 175,341-row file is the training partition.
If you use the Kaggle Parquet files, load them with `pd.read_parquet` and write them out as the two CSVs above.
The notebook checks row counts and per-category counts and stops if they do not match.

## How to run

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook PR02_UNSW_NB15_workflow.ipynb      # then Run All
```

The full run takes about 2 minutes on a laptop CPU. Random seed: 42.
Tested with Python 3.13, pandas 3.0, numpy 2.5, scikit-learn 1.9.
